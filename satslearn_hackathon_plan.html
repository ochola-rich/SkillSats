03 — Lightning

LND REST API Calls

Every Lightning action you need for the MVP — all via the LND REST API. No gRPC needed.

⚡
LND Client Helper utils/lnd.js
const axios = require('axios') const fs = require('fs') const https = require('https') const lnd = axios.create({ baseURL: process.env.LND_REST_HOST, headers: { 'Grpc-Metadata-Macaroon': process.env.LND_MACAROON }, httpsAgent: new https.Agent({ rejectUnauthorized: false }) // dev only }) module.exports = lnd
Endpoint What it does When to call it
POST /v1/invoices Create a Lightning invoice (payment_request + r_hash) User wants to unlock a paid video
GET /v1/invoice/{r_hash} Check if invoice is settled Polling every 2s after showing QR code
GET /v1/balance/channels Check node's channel balance Admin dashboard / health check
POST /v1/channels/transactions Send payment to external wallet (withdrawal) Creator withdraws their earnings
GET /v1/payments List all outgoing payments Admin audit / creator payout history
GET /v1/getinfo Node info (alias, pubkey, synced) Health check on startup
①
Create Invoice — User buys a video
// POST /api/videos/:id/purchase const createVideoInvoice = async (req, res) => { const video = await prisma.video.findUnique({ where: { id: req.params.id } }) const { data } = await lnd.post('/v1/invoices', { value: video.priceSats, memo: `SatsLearn: ${video.title}`, expiry: 600 // 10 min expiry }) // Store invoice in DB await prisma.purchase.create({ data: { userId: req.user.id, videoId: video.id, paidSats: video.priceSats, invoice: data.payment_request, settled: false } }) res.json({ payment_request: data.payment_request, // show as QR r_hash: data.r_hash, // use to poll settlement amount_sats: video.priceSats }) }
②
Poll Settlement + Split Revenue
// GET /api/invoices/:r_hash/status (frontend polls every 2s) const checkInvoice = async (req, res) => { const { data } = await lnd.get(`/v1/invoice/${req.params.r_hash}`) if (data.settled) { const purchase = await prisma.purchase.findFirst({ where: { invoice: data.payment_request }, include: { video: { include: { creator: true } } } }) if (!purchase.settled) { const total = purchase.paidSats const platformCut = Math.floor(total * 0.10) // 10% platform const creatorCut = total - platformCut // 90% creator // Credit creator's custodial balance await prisma.user.update({ where: { id: purchase.video.creatorId }, data: { balanceSats: { increment: creatorCut } } }) await prisma.purchase.update({ where: { id: purchase.id }, data: { settled: true } }) } return res.json({ settled: true, videoUrl: purchase.video.url }) } res.json({ settled: false }) }
③
Creator Withdrawal
// POST /api/wallet/withdraw — creator provides their LN invoice const withdraw = async (req, res) => { const { payment_request, amount_sats } = req.body const creator = await prisma.user.findUnique({ where: { id: req.user.id } }) if (creator.balanceSats < amount_sats) { return res.status(400).json({ error: 'Insufficient balance' }) } // Deduct first (prevent double-spend) await prisma.user.update({ where: { id: req.user.id }, data: { balanceSats: { decrement: amount_sats } } }) // Pay out via LND const { data } = await lnd.post('/v1/channels/transactions', { payment_request, amt: amount_sats // omit for exact-amount invoices }) res.json({ payment_hash: data.payment_hash, status: 'sent' }) }

04 — Build Prompts

Backend Prompts

Paste these into Claude/Cursor one by one. Each is scoped to ~30 min of work.

B1
Project Setup + DB Hour 1
Prompt
Create a Node.js + Express backend for a Lightning-powered education platform called SatsLearn. Set up the project with: Express, Prisma ORM with PostgreSQL, JWT authentication with bcrypt, dotenv for environment variables, and cors. Create this exact Prisma schema with 5 models: User (id, email, username, password, role enum LEARNER/CREATOR/ADVERTISER, balanceSats int default 0, createdAt), Video (id, title, description, url, priceSats, isFree boolean, courseId string, creatorId foreign key to User, createdAt), Purchase (id, userId, videoId, paidSats, invoice string, settled boolean default false, createdAt), Ad (id, title, videoUrl, budgetSats, spentSats default 0, rewardSats int, active boolean), AdWatch (id, userId, adId, earnedSats, watchedAt). Run prisma migrate dev. Create a /utils/lnd.js axios client that reads LND_REST_HOST and LND_MACAROON from env and sets the Grpc-Metadata-Macaroon header with httpsAgent rejectUnauthorized false for dev. Create a basic index.js that starts the server on PORT 4000.
B2
Auth Routes Hour 2
Prompt
Add authentication to the SatsLearn Express backend. Create /routes/auth.js with these endpoints: POST /api/auth/register — accepts email, username, password, role (LEARNER/CREATOR/ADVERTISER), hashes password with bcrypt rounds 10, creates user in DB, returns JWT. POST /api/auth/login — validates credentials, returns JWT with userId and role in payload. Create a middleware /middleware/auth.js that verifies JWT from Authorization Bearer header and attaches req.user. Create /middleware/requireRole.js that takes a role string and returns 403 if req.user.role doesn't match. Add GET /api/auth/me that returns the current user's profile including balanceSats. All error responses use { error: 'message' } format.
B3
Video + Payment Routes Hour 3
Prompt
Add video and payment routes to SatsLearn. Create /routes/videos.js with: GET /api/videos — list all videos with creator username, priceSats, isFree. GET /api/videos/:id — single video metadata (never return url if paid and user hasn't purchased). POST /api/videos — protected, CREATOR only, accepts title, description, priceSats, isFree, courseId, saves uploaded file URL. POST /api/videos/:id/purchase — creates a LND invoice using lnd.post('/v1/invoices', { value: video.priceSats, memo: 'SatsLearn: ' + title, expiry: 600 }), saves Purchase to DB with settled false, returns { payment_request, r_hash }. GET /api/invoices/:r_hash/status — polls lnd.get('/v1/invoice/' + r_hash), if data.settled is true and Purchase not yet settled: calculate creatorCut as 90% of paidSats, platformCut as 10%, update creator's balanceSats += creatorCut, set purchase.settled = true, return { settled: true, videoUrl }. GET /api/videos/:id/access — returns video URL only if user has a settled purchase for that video OR video.isFree is true.
B4
Ads Engine Routes Hour 4
Prompt
Add the ads system to SatsLearn. Create /routes/ads.js with: POST /api/ads — ADVERTISER only, creates an Ad with title, videoUrl, budgetSats, rewardSats. For the hackathon, budget deposit is simulated (just save budgetSats to DB). GET /api/ads/next — returns a random active Ad where spentSats + rewardSats is less than or equal to budgetSats. POST /api/ads/:id/watched — called after user watches the ad video to completion: check the user hasn't watched this ad in the last 24 hours (query AdWatch), if not: create AdWatch record, increment Ad.spentSats by rewardSats, increment user's balanceSats by rewardSats, return { earned: rewardSats, newBalance: user.balanceSats }. GET /api/wallet/balance — returns req.user.balanceSats. POST /api/wallet/withdraw — creator submits a lightning payment_request from their own wallet, backend calls lnd.post('/v1/channels/transactions', { payment_request }), deducts amount from balanceSats first, returns payment_hash. Use a DB transaction for the withdrawal to prevent double-spend.

07 — Demo

Demo Script (5 min)

The story is the circular sat economy. Walk the judges through one full loop.

1
Advertiser deposits budget

Show the ad creation form. Advertiser sets budget 10,000 sats, reward 50 sats per view. "This is attention they actually pay for."

2
Learner watches ad, earns sats

Open Earn page as learner. Watch ad to completion. Show balance tick up +50 sats in real time. "No ad-blocker incentive — you're getting paid."

3
Learner buys a course

Browse courses, click a paid video, show the Lightning invoice QR. Pay using Polar's built-in wallet. Video unlocks instantly. "Zero payment processor, instant settlement."

4
Creator withdraws earnings

Switch to creator account. Show dashboard with earnings. Paste a Lightning invoice, hit withdraw. Show payment_hash. "Creator gets paid in seconds, not 30 days."

⚡
Closing line for judges

"Every platform today monetizes your attention and keeps the money. SatsLearn routes that value directly to you and to the people who teach you — in Bitcoin, in seconds, with no middleman bank. That's the Lightning Network doing what it was built for."
